# N300 桌面控制台

运行 `N300Desk.exe`。第一次连接请开启电脑蓝牙，让 N300 可被发现；连接成功后会保存目标，后续复用同一控制连接。
控制通过 BLE 完成，音频仍由原来的音频线、USB 或蓝牙连接播放。

- **音量**：旋钮支持拖动、滚轮和方向键，停止操作后写入，并回读确认。输入源按音响回复显示。
- **音效**：选择预设；自定义模式下可拖动 EQ 节点修改增益，复位只重置增益。
- **设置**：设备名称、固件、灯光、无信号自动关机、定时关机、连接开关。关闭音箱需要长按。

切换输入时显示“正在切换…”，完成后显示实际输入。短暂等待期间不会重复弹出错误，
没有切换成功时才提示重试。音量、音效等常规设置成功后直接更新控件，不另弹成功提示。
重复打开程序会唤起已有窗口，并提示“程序已在运行”。

标题栏显示“离线演示”时，正在使用模拟设备。命令 `N300Desk.exe --offline` 可启动离线测试版，不扫描或控制真实音响。
模拟模式验证程序行为，不能代替真实固件兼容性验证。

## 更新

应用启动后自动检查更新，有新版时显示提醒；也可以在“设置 → 软件更新”手动检查。
点击“下载并更新”后，程序下载并验证安装包签名，通过后关闭控制连接、原位更新并自动重启。
更新保留安装目录、设置和设备记录；重启后自动删除本次下载的安装包。网络或校验失败时保留当前版本，可重试。
安装期间会短暂释放 BLE 控制连接，音箱保持原来的播放输入。

## 分发

推荐使用 Release 安装包。免安装版本需要**完整复制同一个目录**：

```text
N300Desk.exe
n300/n300.exe
n300/n300.dll
licenses/
README.md
```

普通用户无需 Node、Rust、CMake 或编译工具。Windows 需要 WebView2 Runtime；安装器会在缺少时下载安装。
不应单独复制桌面 EXE；缺失的核心文件会显示启动错误。Debug 与 Release 的文件也不要混用。

## 连接异常

未找到设备时先检查电脑蓝牙、音响是否开机，再关闭手机上的控制 App 后重试。
自动重试期间会显示静止的“等待重试”，可在首页重新连接或停止重试；连接过程中也可取消。
界面遵循 Windows 动画设置，关闭系统动画时会停用界面动画。
出现“连接已中断”时，点击连接音箱重试。
断开连接会停止重连并清除界面当前值，音响仍保持开机；关闭窗口会释放控制连接。

设备不支持或尚未读取成功的设置保持禁用。写入失败会提示错误并重新读取真实值；无法确认时不继续显示猜测值。
多台 N300 的手动选择目前可使用底层命令行，界面尚未提供设备列表。

2026-10-18 已在本机 N300（固件 1.5.1）保持 AUX 输入时验证：重新扫描可发现设备，BLE 连接可读取状态，音量原值写入并回读一致；不需要先切换蓝牙输入。
首次连接失败时检查手机 App 是否仍占用控制连接。不同固件的广播行为需要以实机结果为准。
