# 验证记录

本阶段验证后端整合、模块独立性和前端接口。所有自动设备操作均使用原生离线模式；故障注入使用专用测试模块，不访问实际音响或键盘。两个原生核心此前的实机结果见各模块文档，不能据此替代新桌面应用的整机验收。

`scripts/project.ps1 -Action Test -Configuration Debug|Release` 执行：

| 验证组 | 覆盖 |
| --- | --- |
| N300 原生 5 项 | 协议/API、离线状态、连接复用、工作线程、stdio |
| OG98 原生 4 项 | 协议/回读、离线状态、亮度、stdio |
| Rust 3 项 | 帧长度与 UTF-8、配置原子保存/目录占用、包路径边界 |
| 前端 SDK 3 项 | 读写范围与串行、旧会话取消、乱序响应与关闭 |
| 后端联调 9 项 | 接口清单、排队超时、物理目标绑定、双模块运行、版本替换、故障隔离、停止与旧代次、换设备类型、模块独立运行 |
| 清理保护 4 组 | 缓存留存、构建锁、运行时绑定与锁、目录边界及联接拒绝 |
| TypeScript | 正确调用可编译；缺少设备 ID、值、模块选择及未知方法会报类型错误 |

故障测试实际执行进程退出、长时间不响应、写入后无回复，以及旧命令仍在排队时停止模块。验收要求是其他设备仍可读写、坏包不打断当前实例、写入不自动重放、替换后能力与版本更新。

测试模块只在 `-Action Test` 时构建，不进入发布目录。详细日志位于根目录与各模块的 `artifacts/validation/`；联调的运行记录、数据目录、导出样本按测试运行分别保留，数量和期限由 [清理规则](maintenance.md) 限定。
