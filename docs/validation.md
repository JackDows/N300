# 验证记录

本阶段按后端整合、模块独立运行与替换、前端接口、离线模拟和旧桌面迁移分别验收。常规测试使用原生离线模式；故障注入使用专用模块。真实硬件读取和需要改变设置的实机测试分别记录，不以离线通过替代实机结论。

`scripts/project.ps1 -Action Test -Configuration Debug|Release` 执行：

| 验证组 | 覆盖 |
| --- | --- |
| N300 原生 5 项 | 协议/API、离线状态、连接复用、工作线程、stdio |
| OG98 原生 4 项 | 协议/回读、离线状态、亮度、stdio |
| Rust 3 项 | 帧长度与 UTF-8、配置原子保存/目录占用、包路径边界 |
| 前端 SDK 6 项 | 读写范围与串行、旧会话/排队写入取消、删除重建隔离、乱序响应与关闭、模拟器接口清单 |
| 后端联调 9 项 | 接口清单、排队超时、物理目标绑定、双模块运行、版本替换、故障隔离、停止与旧代次、换设备类型、模块独立运行 |
| 基础功能 6 组 | 原生离线后端与浏览器模拟器分别覆盖全部已声明读取、允许/禁止写入、所有音源和音效、范围边界、全部 EQ 频段、离线关机、连接/重启/替换/删除及同型号多实例 |
| TypeScript | 正确调用可编译；缺少设备 ID、值、模块选择及未知方法会报类型错误 |

故障测试实际执行进程退出、长时间不响应、写入后无回复，以及旧命令仍在排队时停止模块。验收要求是其他设备仍可读写、坏包不打断当前实例、写入不自动重放、替换后能力与版本更新。

测试模块只在 `-Action Test` 时构建，不进入发布目录。详细日志位于根目录与各模块的 `artifacts/validation/`；每次开发结束时按 [AGENTS.md](../AGENTS.md) 手动检查，保留必要日志并删除临时联调副本、截图缓存及多余生成物。

## 真实设备记录

- N300（固件 1.5.1）：保持 AUX 输入连接，已通过 DeskHub BLE 模块读取音量、输入源、预设、六段 EQ、名称和固件版本。
- OG98（三模、当前 2.4G）：已读取全部九项基础能力，包括固件、配置、回报率、灯效和亮度、消抖、休眠、自动系统和键盘选项。
- 本机 N300 固件对 `device.timer`、`device.idleShutdown` 明确返回不支持；`lighting.enabled` 查询超时。保持不可用原因，不能标记为实机通过。
- 两台设备的实机验收通过 31 项检查：保持 AUX 时验证音量、五种预设、设备名称、六段 EQ 和键盘亮度的写入/回读/恢复，并分别重启模块。最终全部读取值与测试前相同；音响恢复音量 10、监听音效，键盘恢复亮度 4，其他灯光参数未变化。
- 另外通过控制接口完成 AUX → 蓝牙 → AUX，回读确认耗时约 1401 ms / 1827 ms；音量和音效保持原值。BLE 控制不要求先切到蓝牙音源。
- OG98 曾在复测时休眠，接收器在线但键盘无应答；用户按 Shift 唤醒后，完整实机验证通过。另一设备在其休眠时仍可完成读取和模块重启。
- 真实关机未执行；其请求路径和状态语义仅离线验证。固件不支持或查询无应答的能力见上，不计入实机通过项。

实机入口必须显式指定已经选择过的目标：

```powershell
node tests/hardware.mjs --targets=artifacts/data/online/devices.json
# 保持当前音源，测试其他可写项并恢复原值：
node tests/hardware.mjs --targets=artifacts/data/online/devices.json --write-and-restore
```

额外指定 `--include-input-switch` 才会测试音源切换。结果位于本次 `artifacts/validation/hardware-*/result.json`；常规 `Test` 不会调用实机入口。精简的本机验收记录在 `research/evidence/acceptance-2026-10-19/` 保留，完整目标和记录不提交公开仓库。
