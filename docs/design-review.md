# DeskHub 0.6 · B「现代平面」交付审查

设计基准为用户于 2026-10-22 选定的 [B 方案](../design/ui-concepts/index.html?style=graphic)。沿用 React、原生 CSS 和 Tauri；正式程序使用真实设备接口，设计样稿保留在独立目录。

0.6.1 连接修复后，重新检查实际安装版的音响页、键盘未连接页与总览：N300 的音量 8、AUX、监听均与硬件回读一致，控制项可用；未连接的键盘与鼠标不展示默认亮度或 DPI。截图未发现本次改动引入的裁切、遮挡或控件样式变化。本轮硬件连接验收见 [验证记录](validation.md)。

## 视觉与操作

| 检查对象 | 实际发现与处理 |
| --- | --- |
| 入口与工作区 | 旧桌搭和模态控制窗不适合 B 的页面结构。改为常驻设备导航、总览与独立控制页；用字号、对齐和黑白面积建立层级。 |
| 总览 | 键盘图形、黑色鼠标控制区、横向音响行与主机摘要对应样稿构图；读数和档位使用真实状态，断开时不继续显示旧值。 |
| 键位编辑 | 初次替换后键盘占高过大，默认窗口下的编辑动作接近底边。收紧页头与键盘占高，编辑栏置于键盘下方；1360 × 900 可看到录入、保存和恢复。最小窗口可滚动完成设置。 |
| 按键选择 | 所有键帽共用一个平面造型，仅选中键反转；改绑标记独立。真实槽位、普通/Fn 层、方向键焦点、组合键及撤销均保留。 |
| 鼠标宏 | 宏库、动作序列与属性/保存区域分工。检查空库、录制后动作、等待时间输入、绑定占用提示、恢复与删除。动作区单独滚动，保存留在属性区。 |
| 草稿与录制 | 返回总览再进入时保留未保存键位；切换页面或录制区失焦时停止捕获，Esc 不跳离当前页面。 |
| 系统与主机 | 设备连接、应用升级、模块下载安装、日志导出及主机库存均使用同一控件样式。主机不展示虚构的温度、负载或驱动控制。 |
| 状态 | 检查读取、断开、未保存、保存后、录制中与模块更新状态。禁用状态仍保留文字和布局；技术详情进入日志。 |

实际渲染检查覆盖 1360 × 900 默认窗口、960 × 680 最小窗口、1920 × 1080 和 375 × 812 浏览器窄布局。键盘改绑、宏编辑等长内容采用可滚动区域，不通过压扁字形或隐藏操作适配。

## 功能验证

`./scripts/project.ps1 -Action Test -Configuration Release` 是构建和回归入口，包括三类原生模块测试、接口与类型检查、跨进程隔离、更新验证、12 组浏览器交互、8 组实际 Windows 程序交互。实际安装与硬件连接检查另行记录，离线模块通过不代表本轮重新验证了所有真实硬件写入。

本机升级验收使用已安装的 `D:\DeskHub\DeskHub.exe`，从 0.4.0 经本地签名更新源升级到 0.6.0，确认重启、绑定/设置保留和下载包删除。

安装版接入原有真实数据时，发现 Windows 对 AppData 的逐文件重定向让逻辑同目录的原子替换报跨盘错误。修正为基于实际文件位置创建和替换临时文件，保持原子替换；未迁移或重置用户数据。最终复测结果与收尾记录见 [验证记录](validation.md)。
