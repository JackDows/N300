# 本地功能清单

当前交付只到基础控制层。下列清单用于保留分析结果，后续按具体需求逐项实现，不代表现有基础程序已包含这些功能。

| 范围 | 原厂证据 | 当前状态 |
| --- | --- | --- |
| 设备通信 | OG98 型号元数据、HID 调用和原厂 getter | 独立 2.4G 直连完成；型号由调用方确认 |
| 基础状态 | 固件、配置、回报率、灯光、消抖、休眠、自动系统、键盘标志 | 读取完成 |
| 亮度 | 当前灯光 setter、0–4 范围 | 写入及回读完成 |
| 常规灯效 | OG98 元数据列出 23 种：常亮、呼吸、波浪等，含自定义、音乐和屏幕联动 | 已保留能力与参数证据；未做模式/颜色编辑器 |
| 本地自定义灯效 | 三个 UserPicture 槽、逐键颜色、配置 store | 待具体要求；未验证导入文件格式与所有帧写入过程 |
| 键位与 Fn 层 | 实际控制器 simple key/Fn 命令、98 键布局 | 待具体要求 |
| 宏 | 实际控制器 simple macro 命令、宏 store、组合键/延时等封装 | 待具体要求；未做宏编辑器或验证全部动作类型 |
| 配置导入导出 | 本地 config/macro/userLight store 与对应界面 | 待具体要求；未实现格式兼容 |
| 其他硬件设置 | 回报率、消抖、普通/深度休眠、自动系统等 | 暂为只读；已保留原厂 setter 证据 |
| 键盘测试/应用外观 | 原厂 keyboardTest/theme store | 待具体要求 |
| 登录、云配置、社区、灯光分享与下载 | 原厂联网模块 | 按需求排除 |
| 固件升级、重置、其他设备专属功能 | 共享类包含相关命令 | 当前不开放 |

共享控制器还含磁轴、OLED、鼠标等方法，不能据此认为 OG98 支持这些硬件功能。音乐/屏幕联动属于本地功能，但需要独立设计音频/画面采集与连续发送，当前没有后台采集。
