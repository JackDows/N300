协议/API 测试包含实际抓包的查询字节、BIT7/BIT8 校验、灯光字段保留、错误/短报文、休眠状态与电量字段区分、旧回复跳过、有限轮询、延迟回读、丢失回复后不重放写入、参数范围/类型、设备型号约束、断开状态和 DLL 内存释放。

需要重做硬件验收时，在原厂后台退出、键盘醒着的情况下运行：

```powershell
.\tests\hardware.ps1
.\tests\hardware.ps1 -BrightnessRoundTrip
```

默认只读取。`-BrightnessRoundTrip` 才会临时降低亮度一档（原值 0 则升到 1），并在 finally 中恢复。若执行中拔掉接收器，恢复无法保证完成，脚本会失败并保留记录，需重新连接后读取亮度。脚本不属于日常离线 CTest。

## 当前限制

- 只在这一只 OG98、当前固件和本机 2.4G 通路完成实测；有线/蓝牙未实现。
- 自动型号 ID 的底层查询仍未解出，扫描只能列兼容接口候选。
- 亮度是在当前自定义灯效槽位完成真实写入验收；其他模式虽保留其原始字段，尚未逐模式实测。
- 键位、宏、导入导出、其他设置写入和完整桌面界面未实现。
- 没有完整性能对比；只证实独立程序不再依赖原厂 Electron/后台，不宣称已定位原厂所有卡顿原因。
