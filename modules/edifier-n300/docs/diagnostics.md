# 诊断与问题追溯

用户提示与工程诊断分别处理。界面表达操作状态、结果和下一步；原始错误保存在本地日志。
不能通过删除错误、直接当作成功或重复发送写入来消除提示。

## 记录与关联

Windows 日志位于 `%LOCALAPPDATA%\local.n300.desktop\logs\n300.jsonl`，每行一个 JSON 对象。
单文件上限 5 MiB，保留当前文件及 3 个轮转文件 `n300.1.jsonl` 至 `n300.3.jsonl`。
日志只写本机，不自动上传。定位历史问题时应及时保存这些文件，轮转会替换最旧记录。

| 字段 / 事件 | 用途 |
| --- | --- |
| `timestamp_ms`、`app_version`、`process_id` | 时间、应用版本与本次进程 |
| `app.started`、`core.starting` | 程序路径、核心路径、是否离线、核心代次 `generation` |
| `core.received` 中的 `ready` | 核心软件版本 |
| `core.request`、`core.received` | 完整 JSON-RPC 请求、响应、状态与原始错误 |
| `operation` | 写入目标、确认结果、每次回读值或错误、总耗时 |
| `core.stderr`、`core.exited`、`app.panic` | 核心异常输出、退出及宿主异常 |
| `ui.error` | 前端错误上下文、原始信息及可用的调用栈 |
| `app.already_running` | 重复启动及已有窗口唤起 |

使用 `process_id + generation + 请求 id` 关联一次命令；操作事件的 `request_id` 对应该命令的 id。
连接事件不一定由用户请求触发，后台重试没有 `request_id`。日志保留 `code/message/details`，
界面按错误类别选择用户文案，未知错误也不直接显示内部异常字符串。
`operation` 事件在宿主落盘后不转发到界面，避免把诊断过程当成用户消息。

排查时记录发生时间、应用版本、用户动作及实际结果，结合相邻的连接事件和请求链判断原因。
日志可能包含设备名称、蓝牙地址和本机路径；提交公开问题时仅附相关片段并去除个人信息。
源码版本通过对应 Git 发布标签定位，测试报告与实机验证记录保存在 `artifacts/validation`。

## 输入源切换误报：0.2.0 → 0.2.1

触发方式：音箱已连接，点击蓝牙输入，立即出现“回读校验未通过”，随后音箱却成功切换。
本机固件 1.5.1 的复现记录：旧核心在约 89 ms 回读到 AUX 并报错，约 1199 ms 后读到蓝牙；
切回 AUX 时约 105 ms 报错，约 1843 ms 后读到 AUX。

原因是把写入后的第一次回读当作最终结果。音箱切换输入是异步的，ACK 与旧输入值都不能证明切换已完成。
0.2.1 使用一次写入、有限时间内查询确认的流程：界面等待，读到目标后结束；真正失败才提示重试。
默认确认窗口为 5 秒，查询间隔 150 ms，取消可立即中断等待；不会重放写命令。
具体配置与事件结构见 [设备接口](api.md)。

回归覆盖延迟生效、持续不生效、取消等待、写入只发一次、界面等待状态，以及日志请求关联。
这样既能避免过渡状态被误报，也能保留真正失败时的预期值、实际值、耗时和错误原因。

修复后在同一台音箱实测：核心分别用约 1.2 秒、1.9 秒确认蓝牙与 AUX，均成功返回；
桌面界面往返切换也通过，每次只发送一次写入，没有错误或成功弹条，最后恢复 AUX，音量保持 10。
对应记录为 `input-switch-baseline.json`、`input-switch-fixed.json`、`input-switch-ui.json`。

## 提示约定

| 情况 | 界面行为 | 工程记录 |
| --- | --- | --- |
| 常规设置成功 | 控件显示确认后的值 | 请求与响应，适用时含确认过程 |
| 输入源正在切换 | 输入区显示“正在切换…”，暂时禁用重复选择 | 保留过渡回读，不产生用户错误 |
| 输入源最终未成功 | “没有切换成功，请重试”，重新读取实际状态 | 原始错误与完整回读过程 |
| 未识别的操作错误 | “操作未完成，请重试” | 原始错误及上下文 |
| 更新失败 | “更新未完成，当前版本保持不变，请重试” | 原始下载、签名或安装错误 |
| 重复启动 | 恢复并聚焦已有窗口，提示“程序已在运行” | 激活事件，不新建控制核心 |

非官方项目说明保留在仓库 README，不出现在日常操作界面。
