# 视觉与交互检查

日期：2026-10-21。范围为独立样稿，不代表生产前端或实机控制验收。

## 整体方案修订

首版把相同功能误做成相同侧栏与三卡片骨架，整体差异主要依赖主题变量。用户指出后，首页模板被替换成三个独立渲染器：工业版采用音量旋钮、音源按键和分组仪器面板；平面版采用字形、黑白图形与不对称布局；未来版采用声音控制列、独立输入控制区与窄导航轨。键位编辑区分别位于右侧、下方和左侧，仍使用相同设备数据和操作能力。

重做后的三张完整首页、三张键盘页和三张宏页已逐一查看。修正了平面版下方编辑区被挤出默认窗口、窄屏编辑器宽度不足和未来版鼠标标题区重叠的问题。测试结果仅证明可操作与规则检查结果，不能替代用户对整体视觉方向的判断。

## 实际截图检查

亲自查看了三套总览、键盘、宏编辑和控件规范的浏览器截图；另查看输入焦点、375px 窄屏键盘、未来版灰阶画面。默认评审尺寸 1440 × 1000；1280、960、375 宽度执行溢出检查。小窗口中键盘在自己的区域横向滚动，编辑器转到下方。

| 项目 | 初次发现 | 修正与结果 | 依据 |
|---|---|---|---|
| 总览对齐 | 鼠标卡片的操作入口高于另外两张 | 统一读数和控制区占位，三张入口重新对齐 | §3.6 |
| 键名 | 窄键帽内 Delete 等名称裁切 | 使用 Del / Ins 等常见缩写，保留完整可访问名称 | §4.1 |
| 平面语言 | 键盘边框太多，接近线框稿 | 使用完整中性底板与平面键块，去掉逐键边框 | §8.5 |
| 工业语言 | 选中与未选中键的浅厚度不够明确 | 统一上亮下暗、下沿厚度和按压反馈 | §6.1 |
| 未来语言 | 仅改边色，不足以说明轮廓差别 | 统一切角、局部边界、分段轨道和序列节点 | §1.4 |
| 保存区 | 编辑器纵向间距使底部说明接近窗口边缘 | 减少组内多余间距，保留组间层次 | §3.6 |
| 焦点 | 切角控件会裁掉外置 outline | 使用控件内部的清晰焦点边界 | §5.7；焦点扩展规则 |
| 悬停可读性 | 深色悬停表面上辅助文字对比偏低；平面版选中行悬停需单独处理 | 使用相应文字与表面配对，纳入矩阵验证 | §5.6 |

截图停在稳定状态，鼠标移出内容区后再拍，避免上一页的悬停位置污染新页面。三种风格的主要区别可从键帽、读数、按钮、输入框与宏步骤中看到；灰阶开关可辅助比较。最终审美方向交由用户选择。

## 自动交互检查

`node design/ui-concepts/review.mjs` 最终通过，结果见 `review-results.json`：

- 三套 × 四个主要页面渲染，无页面脚本错误。
- 每套保留 99 个真实布局键位；选键、组合键修改、保存、Fn 层切换通过。
- 离线状态保留草稿并禁用即时控制；重新连接后恢复操作。
- 切换风格保留当前编辑层与内容。
- 宏延迟修改、步骤移动、空状态、新建、按键录制及保存通过。
- 对照页切换页面、进入相应交互样稿通过。
- 三套专属首页控制通过：工业版旋钮键盘调整、亮度档位；平面版亮度滑块；未来版分段音量控制，以及三套的 DPI 调整。
- 1280 / 960 / 375 宽度下没有页面级横向溢出。

录制与保存是页面内存模拟，不会发送任何硬件指令。一个中间版本在离线禁用逻辑中出现选择器集合错误，已修正并重新运行全套检查。

`check_contrast.py --matrix design-tokens.json`：42 / 42 声明的正常文字配对通过，最低 5.38:1。此矩阵包括主要表面、主按钮及补充悬停配对；禁用态不计入正常文字标准。
