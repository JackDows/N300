# DeskHub 三套视觉提案

评审日期：2026-10-21。当前交付是普通桌面应用的独立交互样稿，用于比较视觉语言。生产前端与设备接口均未改动。

## 打开与比较

直接用浏览器打开 `compare.html`。无需安装依赖、启动服务或联网。

- 对照页可同时查看三套的总览、键盘、宏编辑、控件规范。
- 点击图片或“进入交互样稿”进入 `index.html`，顶部 A / B / C 切换时保留当前页面与编辑内容。
- 勾选“灰阶对照”查看去掉色相后的造型、字重、层次差异。
- 点击底部“预览离线状态”验证断连反馈与编辑内容保留。
- 样稿中的读取、保存、连接与数据均为内存模拟；不会控制硬件、启动 MangoDisk 或写入 G HUB。刷新页面恢复初始内容。

## 对照条件

三套使用相同设备数据、键位布局与任务，但分别设计完整构图。工业版采用顶部导航和仪器式控制面板；平面版采用字号与黑白图形构成不对称主画面；未来版采用窄导航轨、声音控制列和输入设备控制区。三套的首页分别由独立渲染函数生成，不再使用一个三卡片模板。OG98 的 99 个键来自工程的 `modules/flesports-og98/assets/layout.json`，没有替换成泛用键盘图片。

| 系统 | A 精密工业 | B 现代平面 | C 数字未来 |
|---|---|---|---|
| 设计依据 | 精密控制面板 | 现代平面排版 | 功能性数字仪器 |
| 表面 | 哑光、浅层明暗、凹入读数 | 纯净平面，图形与留白分组 | 深色平面，局部边界与角标 |
| 按钮 | 小圆角、浅斜边、短行程压下 | 平直色块、反色、无厚度 | 切角、方向明确、边缘反馈 |
| 字体 | Bahnschrift 数字，清晰中文正文 | 鲜明标题与数字字重 | 技术标签、等宽数值、清晰正文 |
| 键位 | 上亮下暗，选中键面亮起 | 统一平面键帽，选中反色 | 规则几何，选中边界定位 |
| 宏步骤 | 独立操作单元 | 编号、字重、图形组织 | 节点和局部边界表达顺序 |
| 反馈 | 压下 2px，短促提亮 | 明暗变化，保持平面 | 局部线段短暂点亮，完成即停止 |

## 内容与动作层级

主内容是当前设备、选中的键或宏步骤。配置与读数为第二层，连接与辅助说明为第三层。编辑页面突出一个保存操作；同步、恢复、移动等操作降低强调。选择一个键只改变它自身的选中状态，其他键的材质与字体不变化。

即时控制在原位显示数值。键位修改保持草稿，保存后更新当前绑定；普通层与 Fn 层分开。宏编辑包含列表、步骤、延迟、执行方式、空状态和显式录制开始／停止。录制仅捕获当前页面的键盘事件，失焦或 Esc 停止。

## 设计变量

使用原生 CSS，无新增运行依赖。字体优先使用 Windows 内置字体，中文回退至 Microsoft YaHei UI。语义变量映射位于 `styles.css` 的三个主题块；独立构图和专属控件位于 `directions.js` / `directions.css`。原始色阶位于 `tokens.css` 和 `design-tokens.json`。

- 中性阶由 `refactoring-ui/scripts/generate_palette.py --grey --temperature neutral --extended` 生成。
- 强调色沿用 DeskHub 现有 `#82dbe0`，通过同一脚本生成完整色阶。未来版基础表面沿用现有项目变量。
- 正文 14px，辅助 12px，标题与读数使用 20 / 24 / 30 / 36 / 48 / 60 / 72 / 96 级数。键帽受真实物理尺寸限制使用 10–14px；窄屏键盘区域保留横向滚动，不压缩到无法识别。
- 间距使用 4 / 8 / 12 / 16 / 24 / 32 / 48。图标、命中区域与按键几何独立于排版间距。
- 普通字重 400，强调使用 600；平面版标题与动作使用 700，正文仍为 400。
- 三个文字层级对应 `--text` / `--secondary` / `--muted`。颜色以外还使用轮廓、位置与文字传达状态。
- A 控件圆角 8px，容器 12px；B / C 控件平直；C 使用局部切角。阴影仅 A 用于表达浅层厚度，B / C 保持平面。
- 动效 100 / 140ms，遵循 `prefers-reduced-motion`。无持续装饰动画。

## 功能覆盖范围

本轮完整展示：设备总览、OG98 改绑、鼠标宏编辑、控件状态。另提供声音、灯光、主机静态信息作为导航上下文。更新、模块管理、诊断的完整业务界面在方案选定后实施；样稿未安装为正式程序。
