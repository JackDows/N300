鼠标近景复查又发现两处：侧键的黑色凹槽压过了白色按钮本身，中央分缝在前端浮出外壳。已收窄凹槽，分缝与印字通过曲面投影贴合外壳；滚轮保持黑色橡胶，白色机身与白色侧键共用外壳材质。鼠标垫使用独立平面圆角、低对比度缝线；大轮廓和微小倒角分别控制细分，避免用全局增加面数处理局部细节。

交付对象是独立视觉交互样板，使用 Blender 5.2.2 LTS 与 Three.js 0.186.1。正式 DeskHub 安装程序未在本轮替换。

## 验证范围

独立构建与类型检查通过。Edge 在实际预览包 `http://127.0.0.1:1421/visual.html` 上运行六组测试，全部通过：

1. 鼠标悬停与点击打开键盘；99 个实际槽位依次点击命中；选中 F12 前后抽查 Esc、F10 和分号键的像素差异不超过单通道 1/255（浮点光照与抗锯齿量化）；全部键帽复用原对象；回桌面后停止空转渲染。
2. 机箱打开；处理器、显卡、内存、存储、网络的可见区域依次点击命中；空白处关闭；开合中反向切换；Esc 返回。
3. 1280×800、960×640、375×812 的按键设置可达且不遮住选中键。额外人工查看了 1440×900 / 150%、960×640 / 125%、1280×800 / 200% 与 375×812 / 200% 的截图。
4. 强制软件 WebGL 时，在模型请求前拒绝启动。
5. 鼠标在桌面和放大状态均为滚轮朝前、侧键在拇指侧；两枚侧键与白色外壳材质一致；关闭后回到原位。
6. 悬停升起、移开平滑落回；左右音箱之间正确切换；点击右音箱时只浮起右音箱。

最终浏览器审查没有页面脚本或资源请求错误。当前模型为 13,442,232 字节；独立预览包约 14.8 MiB，未包含 Blender 安装目录。

本轮没有进行硬件控制验收：预览中的改绑只保存到会话内，主机显示既有型号信息，不显示模拟温度或占用率。窄屏用于检查控件可达性；完整键盘的主要使用场景仍是桌面窗口。

## 实际窗口性能问题与修复

最初交付窗口继承了个人 Edge 的 `hardware_acceleration_mode.enabled=false`，GPU 子进程带 `--use-angle=swiftshader-webgl`，导致整套场景由 CPU 软件光栅化。此前的截图与点击测试使用独立浏览器上下文，未覆盖这个启动差异。

独立启动器改用工程内的运行配置，实际确认渲染器为 `NVIDIA GeForce RTX 5080 / Direct3D 11`。个人 Edge 设置保持原值。页面创建上下文时要求硬件性能，软件 WebGL 会在加载模型前停止，不能静默转为高负载 CPU 渲染。

同时修复第一次聚焦时的着色器编译停顿：预编译发生在接受输入之前。当前实际可见窗口为 1426×863、150% 缩放。键盘、鼠标与机箱的首次及重复开合中位帧间隔均为 6.1 ms，P95 为 6.1～6.2 ms；首次键盘交互最大值为 30.4 ms，其余开合最大值约 6.2 ms。之前未预编译的首轮停顿为 212 ms。

实际窗口截图还暴露了 Playwright 默认关闭浏览器沙箱产生的顶部提示栏。启动器已显式启用 Chromium 沙箱，重新打开后检查画面与 GPU 性能；没有通过隐藏提示掩盖运行配置问题。

这个结果对应本机和当前窗口尺寸，不代表其他硬件的帧率。软件渲染拒绝路径另有实际浏览器测试；性能记录保留在 `artifacts/visual/performance.json`。
