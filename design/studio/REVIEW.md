# 场景样板审查 · 2026-10-20

交付对象是独立视觉交互样板，使用 Blender 5.2.2 LTS 与 Three.js 0.186.1。正式 DeskHub 安装程序未在本轮替换。

## 画面审查

| 位置 | 发现 | 当前处理 |
| --- | --- | --- |
| 桌面全景 | 支架连接有缝，镜头过远使键盘偏小 | 补上真实连接件，收紧固定镜头和俯角 |
| 键帽 | 平滑法线把大面渲染成软胶，字偏小 | 分离顶面边缘法线，重建有斜壁和凹面的键帽，放大实际刻字 |
| 机箱 | 灯源经玻璃变成白斑；打开侧板出现白面 | 隐藏离线渲染中的光源可见性；实时侧板改用薄玻璃透明材质，灯光随主机移动 |
| 实时画面 | 硬阴影、漂浮感与细线锯齿 | 接触阴影、柔化阴影、MSAA 与最高 2× 像素比；减少屏幕细线密度 |
| 部件选择 | 处理器组的包围盒中心落到主板 | 点击直接命中部件几何；验证点放在处理器可见面 |
| 最小窗口 | 设置卡片遮住功能键一排 | 卡片放在键盘上方，增加实际遮挡断言 |

## 验证范围

独立构建与类型检查通过。Edge 在实际预览包 `http://127.0.0.1:1421/visual.html` 上运行三组测试，全部通过：

1. 鼠标悬停与点击打开键盘；99 个实际槽位依次点击命中；选中 F12 前后抽查 Esc、F10 和分号键的像素完全一致；全部键帽复用原几何；回桌面后停止空转渲染。
2. 机箱打开；处理器、显卡、内存、存储、网络的可见区域依次点击命中；空白处关闭；开合中反向切换；Esc 返回。
3. 1280×800、960×640、375×812 的按键设置可达且不遮住选中键。额外人工查看了 1440×900 / 150%、960×640 / 125%、1280×800 / 200% 与 375×812 / 200% 的截图。

最终浏览器审查没有页面脚本或资源请求错误。当前模型为 14,446,524 字节；独立预览包约 15.7 MiB，未包含 Blender 安装目录。

本轮没有进行硬件控制验收：预览中的改绑只保存到会话内，主机显示既有型号信息，不显示模拟温度或占用率。窄屏用于检查控件可达性；完整键盘的主要使用场景仍是桌面窗口。
