本轮中间稿未通过视觉审查：鼠标横截面过早向内收缩，侧键沿曲面投影后移到外壳上方并被扭曲；同时修改灯光与材质造成表面层次退步。灯光、玻璃参数和桌面材质已恢复上一版，停止把这些参数改动记作改进。

鼠标改用[官方产品页](https://www.logitechg.com/en-us/shop/p/pro-x-superlight-2-se)的三个固定视图核对。顶视图透明轮廓范围为 `(851,285)–(1651,1875)`，从不受侧键遮挡的右侧轮廓采样并按实物长宽归一化。左侧图约束最高点、前端和尾部高度；滚轮遮挡的区间不作为外壳高度。两枚侧键各自建模，保留前键轻微上扬和后键圆尾，不做曲面投影。近景审查另检查前后端的轮廓连续性与印字是否被外壳遮挡。

验收分开记录：全景核对坐姿视角和摆位；顶视、侧视核对鼠标轮廓与分件；原光照下检查材质是否退步；交互测试核对点击与状态。功能测试通过不代表造型、质感或整体美术已经通过用户验收。

当前修正稿的全景俯角为 16.45°，键盘聚焦时保留更多侧壁与外壳厚度。鼠标补齐独立主键、按参考侧视轮廓建模的侧键、滚轮细纹和印字；修正前后轮廓的尖角以及尾部封口产生的小突起。已查看完整桌面、设备近景、鼠标固定顶视/侧视及 125% / 150% / 200% 显示缩放。它仍是待审的视觉样板，本轮没有替换正式安装程序。

最终构建及七组交互回归通过。实际窗口为 RTX 5080 / D3D11、1426×863、150% 缩放；交互帧间隔中位数 6.1 ms、P95 6.1～6.2 ms，首次键盘最大 42.4 ms，重复鼠标最大 12.1 ms。保留实际窗口截图与原始帧时间，不能把该结果当成美术验收。

手动检查并清理了 147.04 MiB 的比较稿、旧预览模型/脚本、构建备份和测试中间文件；在启动实际窗口前另清理独立预览缓存 35.30 MiB。当前视觉产物约 53.59 MiB，其中可运行预览包 20.10 MiB；原始参考证据和正在使用的独立预览配置保留。

## 第三轮的实际窗口性能问题与修复

最初交付窗口继承了个人 Edge 的 `hardware_acceleration_mode.enabled=false`，GPU 子进程带 `--use-angle=swiftshader-webgl`，导致整套场景由 CPU 软件光栅化。此前的截图与点击测试使用独立浏览器上下文，未覆盖这个启动差异。

独立启动器改用工程内的运行配置，实际确认渲染器为 `NVIDIA GeForce RTX 5080 / Direct3D 11`。个人 Edge 设置保持原值。页面创建上下文时要求硬件性能，软件 WebGL 会在加载模型前停止，不能静默转为高负载 CPU 渲染。

加入材质贴图后，清空独立预览的脚本与显卡缓存复测，首次键盘开合仍出现了 502.9 ms 的单帧停顿：仅 `compileAsync` 没有覆盖驱动延迟创建的绘制管线。加载阶段现在还会执行一次聚焦场景的离屏绘制、阴影与法线通道，并等待提交完成后再接受输入。

再次手动清空相同缓存后，实际可见窗口为 1426×863、150% 缩放。键盘、鼠标与机箱的首次及重复开合中位帧间隔均为 6.1 ms，P95 为 6.1～6.2 ms；首次键盘最大值降至 48.6 ms，首次鼠标最大值为 12.1 ms，其余开合最大值约 6.2 ms。首轮仍有短帧波动，不能把中位值描述成全程固定帧率。

实际窗口截图还暴露了 Playwright 默认关闭浏览器沙箱产生的顶部提示栏。启动器已显式启用 Chromium 沙箱，重新打开后检查画面与 GPU 性能；没有通过隐藏提示掩盖运行配置问题。

这个结果对应本机和当前窗口尺寸，不代表其他硬件的帧率。软件渲染拒绝路径另有实际浏览器测试；性能记录保留在 `artifacts/visual/performance.json`。
